# Sabores de la Plaza 🌿

Sitio web estático que conecta a los consumidores con productos frescos, locales y artesanales de la tradición colombiana. Una plataforma digital que lleva la esencia del mercado tradicional a la modernidad.

## 🌟 Características

- **Catálogo de productos**: Galería de productos locales con filtrado por categorías
- **Diseño responsivo**: Adaptado para dispositivos móviles y escritorio
- **Navegación intuitiva**: Menú de navegación con secciones claras
- **Carrusel interactivo**: Presentación visual de productos destacados
- **Formulario de contacto**: Canal de comunicación directo
- **Estética tradicional**: Diseño que refleja la calidez y autenticidad de los mercados colombianos

## 🛠️ Tecnologías

- **HTML5**: Estructura semántica
- **CSS3**: Estilos personalizados con Bootstrap 5.3.8
- **JavaScript**: Funcionalidad interactiva para filtrado de productos
- **Bootstrap 5.3.8**: Framework de diseño responsivo
- **Font Awesome 7.3.0**: Iconos vectoriales
- **Google Fonts (Lora)**: Tipografía elegante

## 🚀 Cómo Usar

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/YessBlack/Sabores-de-la-Plaza.git
   ```

2. **Abrir el sitio**:
   - Simplemente abre `index.html` en tu navegador web
   - No requiere servidor ni instalación de dependencias

3. **Navegar**:
   - **Inicio**: Página principal con información del proyecto
   - **Productos**: Catálogo con filtrado por categorías
   - **Contacto**: Formulario para enviar mensajes

## 🎨 Personalización

- **Colores**: Modifica las variables en `style.css` para ajustar la paleta
- **Imágenes**: Reemplaza las imágenes en la carpeta `img/`
- **Contenido**: Edita los archivos HTML para actualizar textos y productos
- **Filtros**: Modifica `app.js` para agregar nuevas categorías

## 📱 Funcionalidades

- **Filtrado de productos**: Sistema de categorías interactivo
- **Diseño móvil-first**: Experiencia optimizada en todos los dispositivos
- **Animaciones sutiles**: Transiciones suaves para mejor UX
- **Accesibilidad**: Estructura semántica y navegación por teclado
